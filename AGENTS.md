# Project Guidelines & Agent Instructions

## User Directives & Persistent Rules
1. **README.md Maintenance**: Whenever new features, components, API endpoints, or data models are added or modified in the codebase, the agent MUST update `README.md` to reflect those additions and ensure the documentation stays in lockstep with the code.
2. **Device Responsiveness**: Maintain zero horizontal overflow across mobile screens, especially on Google Pixel 7a (412px wide viewport) and other Android/iOS mobile devices.
3. **Streak Tracking**: Ensure user actions that involve completing exercises, challenges, or running code properly preserve and advance the user's Daily Learning Streak.
